# RVQ 残差向量量化编解码

现代神经音频编解码器（SoundStream / EnCodec / Drama 系）把音频表示成**多级离散 token 序列**，RVQ 是核心。

## 原理

1. 第 1 个码本量化原始帧，得到「粗形状」。
2. 第 2 个码本量化「原始帧 − 第 1 级重建」的**残差**。
3. 依次类推，每一级补上上一级没抓到的高频细节。

解码就是把各级码本向量**相加**。量化器越多，重建误差越小、保真度越高。

## 为什么是「token」

编码后每帧变成 `n_quantizers` 个离散码（整数），整段音频 = 短整数序列。这带来两个直接好处：

- **可被语言模型当 token 吃**：语音生成 = 自回归解码 token，统一了文本/语音建模。
- **可压缩**：离散码比浮点采样省空间，且天然适合熵编码。

## 本项目的参考实现

`dramaforge/codec/rvq.py`：确定性码本 + 最近邻搜索。`token_count(n_frames) = n_frames * n_quantizers`，`reconstruction_error` 随量化器数量单调下降（见 `examples/rvq_codec_demo.py`）。

## 可复用要点

- 残差量化是「多级近似」的通用套路，不限于音频（图像 VQ、动作 VQ 同理）。
- 码本初始化用确定性种子即可复现，训练时再换成学习到的码本。
- 判断量化够不够：看重建误差随级数的收敛曲线，而不是拍脑袋定级数。
