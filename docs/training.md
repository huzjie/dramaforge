# 训练（可训练 skill）

mock 后端用一个标量 `skill` 建模「执导遵循度」。训练信号设计成**单调趋 1**：

```python
boost = (skill - 0.5) * 2      # skill=0.5 时 boost=0（随机），1.0 时 boost=1（恒遵守）
p_obey = 0.5 + 0.5 * boost
```

`Trainer.step()` 每次 `skill += lr * (1 - skill)`，曲线干净、可复现。

## 为什么这样做

- 训练信号单调、无「对+1 错-1」的震荡，收敛曲线一目了然
- skill=0.5 时命中率恰好 0.5（随机基线），不会「起点过高」虚报效果
- 这是可训练 mock 的通用套路，历史项目反复验证
